# 按日期字段触发（`DateTrigger`）

## 何时使用

根据 e-builder 数据中的日期/日期时间字段，在指定时机触发。

## 先查询

查询数据源、日期字段、可输出字段和操作人。

## 不可猜测

日期字段必须属于当前数据源；操作人必须是当前租户真实人员对象。

## 最小计划

`dataSource`、`dateField`、`operator`；其余时间规则按需求指定。未明确限制 `queryFields` 时不要传它（或传空数组），CLI 会默认全选主表和系统字段，包含后续链接/赋值需要的“数据ID”。

## 重复周期

`repeatType` 使用平台真实编码：

| 值 | 含义 |
|---|---|
| `1` | 一次（不重复） |
| `2` | 每天 |
| `3` | 工作日（周一至周五） |
| `4` | 每周 |
| `5` | 每月 |
| `6` | 每年 |

不指定时默认为 `1`，即只触发一次。不要把 `1` 当成每日。
