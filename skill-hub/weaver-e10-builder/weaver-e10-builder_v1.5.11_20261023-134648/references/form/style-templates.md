# 表单布局样式模板

`form layout init --style-template <名|id>` 用这些模板初始化布局。

## ⚠ 流式和表格式是**两套独立模板**，不能混用

同一个名字在两套里往往是**不同的 id**（紧凑版 / 轻便版 / 碧海蓝天 / 极简白 / 极简淡蓝 /
清新蓝绿 / 商务蓝 / 淡雅丁香 两套都有），而且各自还有对方没有的模板。所以**解析模板名必须
先知道表单的布局类型**。

| 表单布局 | 接口 | 内置模板数 |
|---|---|---|
| 流式 `FLOW` | `/api/form/flow/template/list` | 24（本环境另有若干用户导入的） |
| 表格式 `EXCEL` | `/api/form/form/layout/template/listTemplateAdvancedByPage` | 20 |

**拿错一套不会报错**——平台收到一个不属于该布局类型的 id，直接忽略；命令照常打印"已初始化"，
样式却纹丝不动。这是最容易踩的坑：改了没效果，还以为模板名写错了。

CLI 已按布局类型自动选接口并校验：传了不属于当前布局那一套的名字或 id 会直接报错，并列出该
布局类型下可用的模板。

## 用法

```bash
# 按名字（按当前表单的布局类型实时解析，推荐）
e10-cli form layout init <objId> <appId> --style-template 碧空如洗

# 按 id（同样会校验它属于当前布局那一套）
e10-cli form layout init <objId> <appId> --style-template 830000000000000022

# 不传则用该布局类型的缺省模板：流式=标准版、表格式=表格版
e10-cli form layout init <objId> <appId>

# 指定视图 + 只读/必填
e10-cli form layout init <objId> <appId> --view-id <viewId> --style-template 紧凑版 --read-only
```

## 注意

- 模板只影响**布局样式**（间距/边框/配色），不影响字段的 readOnly/required（这俩由 `--read-only`/`--required` 或 fields.json 控制）。
- `表格版`（EXCEL 008）历史问题：生成的 comps 默认 readOnly=true。`form layout init` 会显式按 `--read-only`（默认 false 可编辑）覆盖，所以即使用 008 也能可编辑。
- 建表（`form create`）时**不能**指定样式模板，只能建完再 `form layout init --style-template` 换。
