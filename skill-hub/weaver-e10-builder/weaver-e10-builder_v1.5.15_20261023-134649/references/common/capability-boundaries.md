# 平台与 CLI 能力边界

> 下列能力 **CLI 不支持、平台也不支持**。不要声称可以做，也不要输出操作步骤；直接告知用户「当前平台/CLI 不支持」。

| 不支持的能力 | 说明 |
|---|---|
| H5 / 移动端菜单 | 移动端是独立体系（不同 URL + 不同 pageId），尚未整理，禁止编造 |

## 判断「CLI 支不支持」的正确方式

1. 先查 `references/common/ref-cli-commands.md` 的对应命令与参数；
2. 再跑 `e10-cli <命令> --help` 确认当前版本有没有该选项；
3. 仍无法确认时，问用户或如实说明「当前版本没有对应命令」。

**禁止绕行**：不要为了完成配置临时编写 `.mjs` 脚本调用内部接口，也不要让用户直接操作浏览器或设计器代替命令；确认没有命令时，保留该项未完成状态并说明影响。
