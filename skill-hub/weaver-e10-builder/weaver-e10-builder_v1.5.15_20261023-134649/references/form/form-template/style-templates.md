# 表单布局样式模板

## 分类

| 布局 | 模板 | 终端 | 文档 |
| --- | --- | --- | --- |
| 表格式 `EXCEL` | 简易模板 | PC | [简易模板](style-templates-easy.md) |
| 表格式 `EXCEL` | 高级模板 | PC、移动 | [高级模板](style-templates-advanced.md) |
| 流式 `FLOW` | 流式模板 | PC、移动 | [流式模板](style-templates-flow.md) |

## 创建、编辑与应用的公共规则

1. 先确定目标表单的**布局类型和终端**。模板名称可能相同，ID 只在所属布局类型与终端下使用；应用前按目标类型查询并校验。
2. 按模板类别使用对应的原生数据模型。简易模板是参数配置；高级表格式模板是设计器文档；流式模板另有接口和结构，不能仅改 `layoutType` 互相转换。
3. 编辑时先读取完整模板，再合并目标修改，保留未修改的结构、组件、样式、标记和关联 ID。新建时使用有效底稿，设置名称与设计内容。
4. 预览或初始化接口用于核对生成结果，**不代表模板已保存**。模板保存后回读；应用到表单后再次回读表单布局，确认结构和样式生效。
5. 模板定义布局与外观；实际表单的业务字段和字段状态来自目标表单。图片或 Excel 还原出的实际表单布局，需映射到模板规则，不能整份作为模板保存。

设计高级 PC 表格式模板时，先在**模板设置**中确定结构、网格和单元格，再用 **CSS** 调整主题、组件状态和高亮；仅在需要设计器通用属性或行为设置时补充**布局样式**。同一外观尽量在一处维护，具体配置见[高级模板](style-templates-advanced.md)。

当前 CLI 支持表格式简易模板管理，以及高级 PC 表格式模板的最小新建、通用布局样式与网格样式修改。`form layout init --style-template` 能按目标表单布局类型解析并应用相应模板；创建表单后再调用。各类模板的新增、编辑、导入范围以对应的分类文档为准。

自定义高级 PC 表格式模板支持批量启用、禁用和删除；自定义简易模板支持批量删除。实际 PC 流式布局可通过 `form layout save-as-template` 另存其样式为流式模板。系统模板不能修改或删除，具体命令见各分类文档。

```bash
e10-cli form layout init <objId> <appId> --style-template <名称或ID>
```

`--read-only`、`--required` 等选项控制字段状态，不属于布局模板的样式设置。
