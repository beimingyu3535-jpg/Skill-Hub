# 交付物 A · 事实核查报告

## 一、事件还原

| 项目 | 内容 |
|---|---|
| 流传说法 | 「长期使用空气炸锅，会因为美拉德反应导致人体致癌」 |
| 源头 | 2019 年韩国消费者院检测报告：市面 10 款空气炸锅按说明书烹饪冷冻薯条，4 款检出的丙烯酰胺超过欧盟标准，最高的超标两倍多 |
| 传播路径 | 该报告被国内自媒体层层放大，从「部分机型在特定条件下超标」变成「空气炸锅致癌」，再叠加「美拉德反应」这个听起来很化学的词，形成今天的说法 |
| 后续 | 2021—2023 年间，央视网、人民日报、新华网、科普中国、江西省市场监管局等多次公开辟谣 |

## 二、官方 / 权威定性

**结论：这个说法属于「夸大 + 归因错误」，但也不能反过来简化成「完全没事」。**

| 来源 | 定性 |
|---|---|
| 央视网 / 科普中国（2026-08） | 说法「过分夸大」。丙烯酰胺是所有高温烹调都会产生的物质，**并非空气炸锅独有** |
| 新华网引中国农业大学朱雨辰副教授 | 空气炸锅加热原理类似烤箱，但空气流动更快、食物熟化时间更短，「**使用空气炸锅并不会比其他加热方式产生更多的有害物质**」 |
| 国家食品安全风险评估中心《第六次中国总膳食研究》 | 我国人群平均丙烯酰胺摄入量 0.175 μg/(kg bw·d)，比第五次下降 45.1% |
| IARC（国际癌症研究机构） | 丙烯酰胺列为 **2A 类「可能对人类致癌」**，致癌性判断**仅基于动物实验**，对人类是否致癌证据尚不充分 |
| EFSA / JECFA | 未制定健康指导值，用暴露边界（MOE）评估；MOE < 10000 时认为潜在健康风险值得关注 |

## 三、常见误解纠正（四层）

### ❌ 误解 1：美拉德反应会致癌
**错。** 美拉德反应是赋予食品色泽和香味的正常反应（烤面包的焦香、炸薯条的金黄都靠它）。丙烯酰胺是这个反应在**超过 120℃** 时产生的**副产物**，不是美拉德反应本身有毒。把「美拉德反应」当成元凶，是概念偷换。

### ❌ 误解 2：空气炸锅致癌
**错，是归因错误。** 决定丙烯酰胺生成的是**温度和时间**，不是厨具。炒、煎、炸、烤、爆炒只要超过 120℃ 都会产生——用炒锅、煎锅、烤箱一模一样。

**这条最反直觉的数据**：《第六次中国总膳食研究》显示，我国居民丙烯酰胺摄入来源里，**蔬菜占 59.0%**、谷物 18.9%、薯类 10.1%。也就是说，国人摄入丙烯酰胺最主要的途径其实是**日常炒菜**，而不是空气炸锅。

### ❌ 误解 3：无油 = 健康
空气炸锅并非完全无油，炸低脂食材时仍需刷油；它也不能减少食材本身含有的脂肪。

### ⚠️ 修正 1：但「空气炸锅一定比油炸安全」同样不成立
**这一点必须独立核实，因为我查到的是矛盾证据。**

网上流传「《食品科学》研究指出空气炸锅丙烯酰胺比传统油炸降低 90%」——**我用多种检索方式都无法溯源到这篇文献**，所以不采用，请你也不要把它写进稿子。

而我确实查到的、方向相反的证据是：
- Frontiers in Nutrition（2024）：空气炸锅 12.19±7.03 μg/kg，油炸 8.94±9.21，烤箱炸 7.43±3.75——**空气炸锅最高，但组间无统计学差异**
- Food Chemistry（2026，中国农科院马铃薯团队）：复热薯饼时，空气基（空气炸锅/烤箱）351.77–443.94 μg/kg，油基（煎/油炸）93.04–248.27 μg/kg——**空气基反而更高**

**正确的说法是：谁高谁低取决于温度、时间和食材含水量，不取决于厨具类型。** 这比「空气炸锅更安全」更准确，也更有信息量。

### ⚠️ 修正 2：但「完全没事」也不成立
《第六次中国总膳食研究》算出的 MOE 是 **1142，低于 10000 的参考线**，按 EFSA 的判断口径属于「潜在健康风险值得关注」。儿童更敏感——现代预防医学 2024 那篇论文里，2～5 岁幼儿高暴露组（P95）的 MOE 只有 104。

所以准确的立场是：**不必恐慌，但不是毫无问题**；要控制的是温度和别炸焦，而不是扔掉空气炸锅。

## 四、本篇口播稿建议的最终立场

> 这是一个「**辟谣 + 但别辟过头**」的双层结构。

- **该破的**：空气炸锅致癌、美拉德反应致癌 —— 这两个说法都站不住，是夸大和归因错误
- **该立的**：真正的变量是温度和时间；我国居民丙烯酰胺的主要来源是炒菜不是空气炸锅
- **该留的**：丙烯酰胺的膳食暴露确实值得关注（MOE 1142 < 10000），正确动作是控温、别炸焦、多样化饮食

不建议做成单纯的「为空气炸锅平反」，也不建议做成「空气炸锅确实危险」。证据支持的是中间那条线。
