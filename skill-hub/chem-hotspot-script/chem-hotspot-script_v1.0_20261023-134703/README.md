# 化工热点科普口播文档生成 Skill

把一个化工/消费品安全类的热点，做成一份**可直接开拍的科普口播脚本**。

核心特点：**证据驱动**——先做事实核查和文献检索，经你确认后才动笔写稿；文风是"像朋友聊天"而不是念论文；每个说法都做剂量与监管层面的深挖，不做标题党式焦虑。

---

## 一、它解决什么问题

拿到一个热点（"XX 会致癌""XX 被召回""XX 添加剂超标"），如果直接写稿，通常会踩三个坑：

1. 论据来自自媒体或记忆，经不起推敲；
2. 开头就把结论说完，观众 3 秒划走；
3. 要么一味辟谣、要么一味吓人，立场跟着情绪走而不是跟着证据走。

这个 Skill 把流程固化成 7 个阶段，强制先核查再写稿，并把"完播率"和"合规性"拆成可逐条自检的规则。

---

## 二、安装

### 前置条件

- WorkBuddy（或兼容 Agent Skills 的环境）
- 若要输出 **docx**，需同时启用内置技能 `tencent-local-office-edit`
  （脚本路径示例：`~/.workbuddy/plugins/cache/workbuddy-builtin/skill-tencent-local-office-edit/*/edsdk.py`）
  只想要 Markdown 稿则不需要它。

### 安装步骤

把 `chem-hotspot-script` 整个文件夹放到技能目录下：

| 范围 | 路径 |
|---|---|
| 个人级（推荐，全项目可用） | `~/.workbuddy/skills/chem-hotspot-script/` |
| 项目级（仅当前项目） | `<项目目录>/.workbuddy/skills/chem-hotspot-script/` |

Windows 下 `~` 即 `C:\Users\<你的用户名>`。

放好后**重启会话**，技能才会被识别。

---

## 三、怎么用

直接给一个热点就行，不需要额外指令：

> 「长期使用空气炸锅，会因为美拉德反应导致人体致癌」
> 「XX 牌保鲜膜加热后会释放塑化剂」
> 「白菜蘸甲醛保鲜，还能不能吃」

技能会自动跑下面的流程。

---

## 四、它会产出什么

**两段式交付**，中间有一个不能跳过的确认卡点。

### 第一段：事实核查 + 文献清单（等您确认）

- **交付物 A｜事实核查报告**：事件还原 → 官方定性 → 常见误解纠正。每条结论标注来源与时间，并归类为「已证实 / 存疑 / 谣言」。
- **交付物 B｜文献清单**：期刊真实题录（GB/T 7714 格式）+ DOI + 支撑论点 + 关键数据。

> ⚠️ **重要分工**：本 Skill **无知识网权限**，无法下载全文。它通过公开渠道定位**真实存在**的论文并给出标准题录，但**真伪需要您在知网做最终复核**。请务必在写稿前核实。

**确认无误后**才进入下一段。

### 第二段：口播稿 + docx

- 六层递进结构（现象 → 材料 → 机理 → 剂量 → 区分 → 实操 → 收束）
- 正文约 **1200 字**（Word 口径），成片约 4–5 分钟
- 文末附「引用来源清单」表格
- 先出 Markdown 供改字，确认后转 docx

## 五、可定制项

| 项目 | 说明 |
|---|---|
| **人设与签名** | 默认沿用「老谢」+「大道至简，我是老谢，关注我，带你看透行业真相」。换人设请改 `SKILL.md` 的「默认约定」一节。 |
| **输出格式** | 默认 Markdown → docx。不需要 docx 可忽略阶段 5 的转换路径。 |
| **字数** | 默认 1200 字。要长/要短改 `SKILL.md` 文风要求第 14 条。 |
| **时间轴标注** | 可选为每段标注时间段（如 `【0-25s｜第一层：…】`）。 |


## 七、要点速览（写稿时最常踩的坑）

1. **钩子先立"预期"再砸掉**——不说"有东西可能有害"，而是"你以为买它是为了健康？少了油就一定少了风险吗？"
2. **钩子里不点名任何术语**——"丙烯酰胺""AGEs"会劝退小白，用"一些你看不见的变化"代替。
3. **术语下沉**——"席夫碱""Strecker 降解"这类词全部换成大白话，专业名词只在必要时出现一次并紧跟解释。
4. **数字不连着砸**——三个以上数字要拆开，中间插转折或情绪缓冲。
5. **"没证据"必须写严谨**——后面一定跟上限定语，避免被听成"绝对安全"。
6. **避开平台风控词**——"下毒""投毒""致命""害你"等易被判夸大，冲突感改用"最荒诞的是""排第一的居然不是它"。
7. **立场跟随证据**——证据指向没事就辟谣，指向有问题就警示，不预设、不为流量制造焦虑。

## 八、已知边界

- 无知识网权限，文献真伪需用户复核（见第四节）。
- 与**厨具、家电、新兴消费品**相关的选题，中文期刊研究往往极少，主流证据在英文期刊，会出现中英文献混用的情况——这是正常的，不是凑数。
- 媒体转述的「某项研究指出」若无法独立溯源到原刊，会被直接剔除并在交付物中留痕说明。
