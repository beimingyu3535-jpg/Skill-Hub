# 口播稿结构范式与样例

本文件是从用户 5 份成品模版中提炼的共性。写稿时严格对齐。

---

## 一、五份模版的共性

| 要素 | 观察到的规律 |
|---|---|
| 标题 | 热点 + 反常识悬念。如「你以为减肥是掉肉？其实脂肪是从鼻子里出去的」「一个密封塞，为什么让几十万只焖烧罐被召回？」 |
| 形式声明 | 固定一行：`形式：口播为主，画中画贴 XX 截图、XX 图` |
| 开篇 | `（画面：XXX）` + `【0-3秒 · 钩子】` + `口播：` |
| 分部分 | `【第X部分 · 小标题】` / `【0-25s｜第X层：XXX】` + `（画中画：XXX）` + `口播：` |
| 文献引用 | 正文内嵌：`《期刊名》+ 年份 + 核心结论`，部分模版直接附链接 |
| 收束 | 互动提问（`评论区聊聊：……`）+ 固定签名 |
| 文末 | `附：引用来源清单` 表格：`序号 | 来源期刊/机构 | 年份`（模版1 有此表） |
| 语气 | 口语、短句、大量设问句推进（「那问题来了」「你以为就这样了？恰恰相反」） |

### 被反复使用的推进句式（可直接复用）
- 「你以为 X？其实……」
- 「先别急着骂品牌，我们先搞懂……」
- 「那问题来了——」
- 「讲到这里，很多人可能以为剧情又要往 XX 方向发展了。恰恰相反。」
- 「关键在于两个字——」
- 「说白了，……」
- 「这件事最可怕的，不是 XX，是……」

## 二、结构范式（逐字段）

```
视频标题：<热点 + 反常识悬念>
形式：口播为主，画中画贴 <素材类型清单>

（画面：<开拍画面，需零拍摄难度>）
【0-3秒 · 钩子】
（画中画：<素材>）
口播：
<反常识断言 / 具体数字 / 直接质问。禁止寒暄、禁止自我介绍、禁止说结论>

【第X层 · <小标题>】<（约XXX字）可选>
（画中画：<素材>）
口播：
<本层开篇留悬念 → 展开 → 层末抛出下一层的问题>

……（按六层递进依次展开，每层至少嵌 1 处文献）

【收束层】
（画中画：<素材>）
口播：
<从个案上升到行业/认知>

【结尾】
（结尾画面：<画面>）
口播：
<价值观收束一句>
评论区聊聊：<互动提问>
大道至简，我是老谢，关注我，带你看透行业真相。

附：引用来源清单
| 序号 | 来源期刊/机构 | 年份 | 支撑论点 |
|---|---|---|---|
| 1 | 《XXX》 | 20XX | …… |
```

**注意**：六层递进是本 Skill 的固定骨架，模版里层数不完全一致（模版4 是「第二层/第三层/第四层」，模版5 自带时间轴）。**以六层骨架为准，命名上可自由调用「第一层/第二部分」。**

## 三、完整样例（对齐模版5 的成品形态）

> 这是终稿应该长成的样子。层数、时间轴、文献嵌法、收束方式全部照此执行。

```
视频标题：白菜蘸甲醛保鲜，白菜还能不能吃了？

形式：口播为主，画中画贴新闻截图、官方通报截图、化学特性示意图、字幕公式

（画面：怼脸，手里拿一颗白菜）
【0-3秒 · 钩子】
（画中画：快速闪过事件新闻标题 + 现场蘸取甲醛瓶子实拍图）
口播：
白菜蘸甲醛保鲜冲上热搜。先声明一句——这不是所有白菜都有问题，
但也不是「蔬菜自带甲醛，不用管」就能糊弄过去的。
今天用几分钟把来龙去脉、风险高低、怎么防范，一次说透。

【0-25s｜第一层：还原事件事实】
（画中画：政府通报截图、暗访现场视频片段）
口播：
官方通报已经定性：收购商用甲醛泡白菜根保鲜，违法，已立案追查。
评论区吵成两派：一边说「所有白菜都不能吃了」，一边说「蔬菜自带甲醛，不用管」。
先区分两个概念——内源性甲醛 vs 外源性甲醛。
《广东农业科学》2022 年研究指出，大白菜自身代谢会产生微量甲醛，
本底含量大约 0.1 到 3 毫克每公斤。这是天然的，剂量极低，正常吃没有任何问题。
但这次曝光的是外源性甲醛——人为违规添加。
《中国卫生检验杂志》研究提到，不法商贩利用甲醛强杀菌特性浸泡菜根，
抑制腐败、漂白卖相。
关键一句话：我国明令禁止甲醛作为食品加工助剂使用。
天然自带的，和人为泡进去的，是两码事。

【25-75s｜第二层：它到底是什么、怎么起作用的】
（画中画：甲醛分子结构图、溶液浸泡示意图）
口播：
那问题来了，甲醛到底是个什么东西？
它是分子量最小的醛，极易挥发，又极易溶于水。
这两个性质，正好解释了商贩为什么选它——
溶得进菜根，又能在卖相上看不出来。
但也正是这两个性质，埋下了后面风险的伏笔。

【75-145s｜第三层：风险评估，讲清剂量逻辑】
（画中画：风险评估文字字幕 + 简单公式动画 + 甲醛易溶于水示意图）
口播：
甲醛泡过的白菜，吃了会不会出事？
甲醛是 IARC 一类致癌物，但食品安全永远不能抛开剂量。
《中国食品卫生杂志》引用美国 EPA 数据：甲醛每日允许摄入量 0.2 毫克每公斤体重。
60 公斤成年人，一天安全上限约 12 毫克。
正常农贸市场蔬菜本底甲醛平均 0.27 毫克每公斤——
也就是说，你一天得吃四十多公斤蔬菜，才能碰到底线。
但被人为高浓度甲醛浸泡过的白菜根部，局部残留会显著超标。
吃一两颗不会急性中毒，但长期反复摄入外源性甲醛，
黏膜刺激、慢性健康风险客观存在，不能拿「剂量低」来洗白违法行为。
而且甲醛易挥发、易溶于水，残留大多集中在被浸泡的菜根部位，
不会完整渗透进内部菜叶。

【145-210s｜第四层：消费者实操建议 + 行业思考】
（画中画：清洗步骤示意图、剥叶对比图）
口播：
那普通老百姓买菜该怎么办？
第一，优先选正规商超、菜市场。
第二，买到白菜，直接切掉一大截菜根，剥掉外层受损叶片。
第三，用流动清水浸泡冲洗，烹饪充分加热——高温可以进一步挥发甲醛。
大白菜含水量高，长途运输损耗最高可达 30%，正规冷链成本高，
个别商贩铤而走险用甲醛保鲜。这件事最可怕的，不是甲醛本身。
是做违法的事的人，赌的是「反正消费者看不出来」；
是网上吵成一片，真正该知道的真相却没几个人说清楚；
是非法添加的成本，远低于正规保鲜的成本——
这个问题不解决，今天禁了甲醛，明天还会有别的。

【结尾】
（结尾画面：怼镜头）
口播：
大道至简，我是老谢，用专业打破信息差，还有什么想看的，评论区留言。

附：引用来源清单
| 序号 | 来源期刊/机构 | 年份 | 支撑论点 |
|---|---|---|---|
| 1 | 《广东农业科学》 | 2022 | 大白菜内源性甲醛本底含量 0.1–3 mg/kg |
| 2 | 《中国卫生检验杂志》 | — | 酚试剂衍生法测定白菜中的甲醛；商贩浸泡菜根抑制腐败 |
| 3 | 《中国食品卫生杂志》 | — | 引用 EPA 数据，甲醛每日允许摄入量 0.2 mg/kg 体重 |
```

## 四、写作时最容易跑偏的地方

1. **开头就报结论**。这是最高频的错误。钩子只负责制造疑问，不负责给答案。
2. **文献变成装饰**。文献必须落在具体论点上，不能整段只有"有研究表明"。
3. **画中画写超纲**。出现"主持人走进仓库""特写手撕包装"这类要求，直接删。
4. **结尾变成说教**。收束要落在"认知升级"，不是"所以大家一定要注意"。
5. **字数失控**。六层平均每层 150–200 字，加上钩子和结尾刚好 1200 左右。
