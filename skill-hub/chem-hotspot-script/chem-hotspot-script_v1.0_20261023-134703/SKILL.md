# 化工热点科普口播文档生成 Skill

把一个化工类热点，做成一份可直拍的科普口播脚本。

## 何时用

用户给来一个化工/材料/消费品安全类的热点（事件、传言、产品争议），要一份科普口播文档时。典型说法：「帮我写个 XX 的口播」「这个热点能不能做一期」「按模版给我出一份口播稿」。

## 铁律（违反任一条即返工）

1. **不自行选题**。热点只能来自用户，不替用户判断选题边界、不擅自换题或扩题。
2. **禁止编造文献**。期刊名、年份、期号、作者、数据全部必须真实可查。查不到就如实写「该论点暂无可查期刊文献」，绝不用自媒体、网页软文或编造数据凑数。
3. **文献必须过用户的手**。产出文献清单后**停下来**，等用户在知网逐条核实通过，才允许动笔写正文。绝不带着未核实的论据写稿。
4. **结论后置**。前 3 秒只给现象和悬念，第 1 层禁出现结论；答案要到第 4–5 层才被推出来。
5. **零拍摄难度**。画中画只用现成可获取的素材，禁止要求实拍、外景、真人多动作演示、定制道具、复杂后期。
6. **立场跟随证据**。证据指向「没事」就做反向辟谣，指向「有问题」就明确警示，不预设结论、不为流量制造焦虑。

## 能力边界（须主动向用户说明一次）

本 Skill 无权访问知网，无法下载全文。能做到的是通过公开渠道定位**真实存在**的期刊论文，给出标准题录与检索式；**真伪与正文细节由用户在知网做最终复核**。不要假装读过全文。

## 工作流

### 阶段 0 · 热点拆解
把热点拆成三组待核问题，先发用户确认没走偏：
- **事实层**：发生了什么？谁在说？有无官方通报？时间地点主体、处理结果？
- **科学层**：涉及哪些化学物质/材料/工艺？性质是什么？
- **剂量层**：剂量—效应关系？天然本底值 vs 人为添加值？实际暴露量多少？

产出：3–6 条待核问题清单。

### 阶段 1 · 事实核查（交付物 A）
信源优先级：官方通报/监管部门 > 权威机构（WHO/EPA/CPSC/IARC 等） > 主流媒体 > 自媒体。

每条结论标注来源与时间，并明确归类为 **已证实 / 存疑 / 谣言**。热点里站不住的说法直接指出错在哪。

产出结构：事件还原 → 官方定性 → 常见误解纠正。

### 阶段 2 · 文献检索（交付物 B）
检索思路：`物质名/材料名/危害名` × `检测 | 迁移 | 风险评估 | 毒理 | 代谢 | 暴露`。

优先中文期刊（知网可查），命中率较高的刊物：
《食品安全质量检测学报》《中国食品卫生杂志》《食品工业科技》《食品科学》《现代预防医学》《环境与健康杂志》《广东农业科学》《中国卫生检验杂志》《广州化工》《塑料工业》《饮料工业》《中国学校体育》《大众健康》《国外医学·内分泌学分册》

必要时补英文文献（PubMed / PMC / BMJ 等），模版里已有先例。

**输出格式（GB/T 7714）**：
```
[1] 作者. 题名[J]. 刊名, 年份, 卷(期): 起止页码.
```
每条后附三行：
- **支撑论点**：支撑稿子里哪句话
- **关键数据**：可直接引用的数字/结论
- **可核验线索**：DOI 或 `刊名+年份+期号+题名` 检索式

数量 3–5 篇，另可加官方通报/权威机构来源。

**⚠️ 转述文献必须独立溯源。** 媒体（包括人民日报、央视这类权威媒体）常写「一项发表在《XX》上的研究指出……」却不给题录。这类转述**必须独立核到原刊**才能用；核不到就剔除，并在交付物里留痕说明剔除了什么、为什么。实战中已遇到「网传《食品科学》研究称空气炸锅丙烯酰胺降低 90%」，多渠道均无法溯源，直接弃用。

**⚠️ 证据矛盾时不要强行站队。** 同一问题查到方向相反的文献是常态（如「空气炸锅 vs 油炸谁的丙烯酰胺更高」，英文文献里有说更高、有说更低、有说无差异）。此时正确做法是把矛盾如实呈现，并把结论从「A 比 B 好」改写成「取决于 C 和 D，而不是 A 还是 B」——这通常比原选题更有信息量。

**⚠️ 中文期刊覆盖不均。** 与厨具、家电、新兴消费品相关的选题，中文期刊研究往往极少，主流证据在英文期刊。遇到这种情况如实说明，中英混用，不要为了「全是知网文献」而凑数。

### ⛔ 确认卡点（Gate）
把交付物 A + B 一起给用户，等用户确认三件事：事实结论成立、文献真实且支撑对应论点、无需补查删改。

**通过才进入阶段 3；不通过退回阶段 1/2 重查。** 这是流程里唯一不能跳的硬卡点。

### 阶段 3 · 结构设计（六层递进骨架）
| 层级 | 解决的问题 | 手法 |
|---|---|---|
| 1 现象层 | 热搜是什么？多数人的第一反应是什么（通常是错的） | 反常识断言钩子 |
| 2 材料层 | 这东西到底是什么做的？ | 成分逐项拆解 |
| 3 机理层 | 怎么进入身体/怎么起作用？ | 生活化类比 + 文献① |
| 4 剂量层 | 到底多危险？ | 把剂量算给观众看 + 文献②③ |
| 5 区分层 | 哪些是天然本底，哪些是人为违法/工艺缺陷？ | 概念切割（内源 vs 外源）+ 文献④ |
| 6 实操层 | 普通人具体怎么办？ | 3–5 条可执行动作 |
| 收束层 | 从个案上升到行业/认知 | 文献⑤ 或官方口径 |
| 结尾 | 互动 + 固定话术 | 沿用模版风格 |

### 阶段 4 · 撰写口播稿
**字数口径**：正文口播 ≈1200 字（不含标题、形式声明、画中画提示、引用清单），≈4–5 分钟成片。

**验收按 Word 口径算**：中文字符数 + 英文单词数 + 数字串数。**不要用「含空格字符数」**——数字和拉丁字母前后的空格会把结果虚高两三百字，容易误判超标而过度删减。统计时排除：视频标题行、`形式：` 行、`（画中画…）`/`（画面…）` 行、`【…】` 小标题行、`口播：` 行、`附：引用来源清单` 之后的所有内容。

**文风要求（用户明确提过，权重等同铁律）**：

1. **钩子必须贴近日常生活**。用观众自己的场景开场，不要用新闻事件开场。推荐结构：先复刻一个具体生活瞬间（时间＋动作＋自我安慰式的心理活动），再甩出那个吓人的说法，最后落一个**两难式反问**，把观众按在座位上。
   - 好：「晚上十一点，一包冷冻薯条倒进空气炸锅，一百八十度，十分钟…然后你刷到一句话：会致癌。你手里那根薯条，是放回去，还是一口吃掉？」
   - 差：「2019 年韩国一份检测报告让空气炸锅冲上热搜」——这是新闻开场，跟观众没关系。
   - 通用禁区：寒暄、自我介绍、「今天我们来聊聊」这类开场，一律删掉。
   - **⚠️ 第一句打「健康焦虑」，不要打「产品」。** 观众不关心某个具体物件，只关心自己会不会被伤到。所以先给"你每天吃/用的东西可能有问题"的焦虑，**第二句才落到争议对象**（空气炸锅、保鲜膜、某某添加剂）。实战中被用户否掉的写法：首句「你家那台空气炸锅，烤鸡翅、炸薯条、煎五花肉，香得不行」——把产品放在了第一句，代入感反而弱。改成「你每天吃得最香的那几口——烤鸡翅、炸薯条、煎五花肉，网上说它们致癌、伤肝肾、还加速衰老」后明显更强。
   - **⭐ 最强钩子范式：预期违背 ＋ 悬念不点名。** 比单纯抛焦虑更抓人的写法是——**先立起观众已有的预期（他为什么买/为什么信），再一句话把它砸掉**。实战最终版（用户连改两稿定下来的）：
     > 很多人买空气炸锅，就是为了两个字：健康。少放油，不用传统油炸。
     > 但问题是：少了油，是不是就一定少了风险？
     > 因为食物在高温下变香、变脆的同时，也可能发生一些**你看不见的变化**。
     前半句是观众的**购买动机/信念**（买它=健康），后半句用一个反问把它推翻（少油≠少风险）。这种结构同时完成"代入"和"悬念"，比"你每天吃的东西可能有害"这类直接恐吓高级得多。
   - **⚠️ 钩子里不要点名任何具体物质或术语，用「看不见的变化」这类悬念表述。** 用户中途写过一版点名版钩子（"丙烯酰胺、AGEs，一个和致癌风险有关，一个和衰老有关"），最终自己删掉了——因为**点名=劝退**：观众不认识那两个词，也等于提前把悬念泄了。改成"你看不见的变化"，三个好处：① 不劝退小白；② 不限定指控数量；③ 悬念留到正文才揭晓。
   - **⚠️ 首尾指控数要对齐（点名版才会踩的坑）。** 如果钩子点名了 N 条指控，正文就要判决 N 条；只立 2 条、正文却判 3 条、标题也说 3 条，就是首尾口径不一致。**用"悬念不点名"写法可以天然规避这个坑**——这也是它更优的原因之一。

2. **要有活人感，允许吐槽**。不要严肃科普腔。遇到槽点直接吐槽：把营销话术点名（「'无油就是健康'这话，是营销文案写的，不是科学家写的」）、拿观众自己的糗事开玩笑（「炸过头，薯条黑得像煤球，你还硬着头皮吃了两根」）、拆媒体的台（「把一个行业努力目标，说成了老百姓的生死线」）。专业但不端着，像跟朋友聊天。

3. **必须有「大家都不知道」的深挖层**。只讲「有没有毒」是浅的。要往背后的**标准逻辑、监管空白、产业链、文化习惯**上挖。实战中最好用的一类料是：
   - 这个「超标」超的到底是什么标准？是安全线还是行业基准值？
   - 有没有限量标准？为什么没有？（如丙烯酰胺属基因毒性致癌物，推不出安全剂量，只能走 MOE＋ALARA）
   - 国标管的是「怎么测」还是「限多少」？
   - 主要暴露来源的构成，暴露出的是不是一种**错位的焦虑**？
   这类内容才是「专业」的实质，比堆数据更值钱。

4. **段落结尾禁止总结，最后才升华或反转**。每一层不许出现「所以……」「由此可见……」「总的来说……」。改法：每层末尾留一个**接续性的疑问或悬念**（「那为什么不限？」「那中国人真正是从哪吃进去的？」），把观众推进下一层。全片只在最后一层做一次反转＋升华：
   - 反转：把观众的注意力从「他以为的元凶」扳回「真正的元凶」。
   - 升华：给一句能记住的判断（如「热搜给你的永远是结论，但化学只认条件」）。

5. **钩子必须短，两句话、40 字以内**。一句生活锚点 ＋ 一句直击痛点的反问，到此为止，不准铺垫。痛点要落到观众的实际损失上（心疼钱、心慌、舍不得扔），不要落到信息上。
   - 好：「薯条扔进去十分钟就出锅，香得很。可你有没有想过——你炸的到底是薯条，还是致癌物？」（38 字）
   - 差：先讲时间、温度、操作流程，再讲刷到什么消息，最后才反问——三段铺垫，观众早划走了。

6. **段间衔接要自然，不许硬切**。每层开头加一句**承接语**，先把上一层的话头接住，再转到本层。常用句：「讲到这儿你可能会想……」「先别急」「标准说完了，还有个更扎心的问题……」「那它是怎么被造出来的？」「话说到这儿……」。上一层的收尾疑问和下一层的承接语必须咬合上。
   - **⚠️ 承接语只用于"层与层之间"，不用于"钩子 → 第一层"。** 第一层要**直接上定义**，首句就是「XX 是……」，不要写「要聊这事，得先请出一位挨骂的主角」这类硬过渡——用户明确否掉过这种写法。开篇最快的抓法是给概念下一个 15 字内的人话定义，再补具象例子。
   - **⚠️ 话题跳跃要加"桥"。** 当相邻两层讨论的是**不同话题**（如第三层讲"标准与监管"、第四层讲"暴露来源构成"），光有承接语不够，会显得"突然跳"。要在新层开头补一句**把两个话题缝起来的桥**，句式是"前者说完了，但真正跟 X 有关的是另一件事"。实战写法：「标准的事说到这儿。但真正跟每个人有关的，是另一笔账——我们天天吃进去的丙烯酰胺，到底打哪来？」

7. **禁止把文献句式直接搬进稿子**。机理链、标准名、法规号、统计口径这类内容最容易生搬硬套，必须转成口语——但**观点和相关数据一个字都不能改**。
   - 生搬（×）：「美拉德反应经席夫碱、Amadori 重排，最后在 Strecker 降解阶段生成丙烯酰胺」
   - 口播（√）：「糖和氨基酸开始'变脸'，一路反应下来，丙烯酰胺就出来了」
   - 生搬（×）：「现行国标 GB 5009.204 规定的是检测方法，不涉及限量指标」
   - 口播（√）：「我们的国标 GB 5009.204，管的是怎么测，不管限多少」

8. **钩子可以泛化，但钩子里挖的每个坑正文必须填**。用户有时会把钩子从"单一指控"改成"生活场景 + 多个指控"（如从"空气炸锅致癌"扩成"致癌、伤肝肾、加速衰老，三个说法一次验完"）——这通常比只抓一条更有吸引力，因为它覆盖了观众心里所有没说出口的疑问。但**钩子一旦列了 N 条指控，正文必须逐条判决**，否则开头越吓人、结尾越漏气。收口用固定三段式：**「先说 X／再说 Y／那 Z 呢」**。
   - 判决只有三种合法结果：**被夸大 / 没证据 / 确有来头**。三种都可以说，但要各自挂上证据。
   - 若某条指控找不到任何证据根，**要么把钩子缩回一条，要么在正文里明确写"这条没证据"**，绝不放着不管。
   - 实战案例：「加速衰老」原本看着像纯谣言，深挖后发现有真实机制根——AGEs（晚期糖基化终末产物），也是美拉德反应的副产物。找到这条根后，三个指控才能被归到同一条主线（温度/时间/剂量）上，收束层的反转才立得住。**先找证据根，再决定钩子敢不敢放大。**

9. **专业术语必须下沉，密度压到最低**。机理层最容易写成课堂。原理链保留，化学名词换大白话。
   - 删：「席夫碱」「Amadori 重排」「Strecker 降解」「还原糖/天冬酰胺」→ 换成「糖和氨基酸开始'变脸'，一路反应下来」
   - 术语只在必要时出现**一次**，且紧跟一句大白话解释（如 AGEs → 「糖和蛋白质在高温下'粘'在一起、变硬变脆的那玩意」）
   - **⚠️ 3 秒钩子内禁止出现任何专业术语**。术语首次登场必须挪到第一层，且在钩子已经抓住观众之后。实战中被用户否掉的写法：钩子里写「香得不行，靠的都是美拉德反应」——观众还没被抓住，先被术语劝退了。

10. **反转点要提前制造冲突，但揭晓仍留在原层**。如果某层是全片最有价值的反转（如「真正的产毒大头根本不是它」），不要让它冷启动。两个动作：
    - 在更早的层末尾埋**悬念**（「先别急着给它发奖状——我告诉你一个数，你会对'到底谁该背锅'彻底换个想法」）
    - 给反转层的**标题加冲突感**（「中国人到底吃进去多少」→「那到底是谁，在给你'下毒'」）
    - **制造冲突 ≠ 提前揭晓**。悬念可以提前，答案必须留在原来的层。提前揭晓就不叫反转了。

11. **「没证据」必须写严谨，绝不能听成「绝对安全」**。辟谣稿最容易在「XX 没证据」这句翻车。标准三层写法：①「至少目前的研究，没有把 A 列成它的靶点」→ ②「证据更明确的是 B」→ ③「没被证实，不等于不存在，只能说，矛头暂时不指向 A」。只要出现"没证据/无证据"，后面必须跟一句限定。

12. **数据不要念论文**。数值一律保留，但换算成体感表达。
    - ×「平均摄入量为 0.175 μg/(kg bw·d)，60 公斤成人每日约 10.5 μg」→ √「你一天吃进去的那点量，跟喂出肿瘤的那个量，中间隔着五六十倍」
    - ×「国际上采用暴露边界值（MOE）评估」→ √「国际上算的不是这笔账，他们看的是另一样东西，叫暴露边界值」
    - 硬数字（120℃、180℃、59%）可以直给，但**成串的换算过程和专业量纲必须口播化**。

13. **这是科普，不是实验**。全程不承诺"做实验""实测""验证给你看"。钩子和结尾的承诺话术用**「说清楚 / 讲清楚 / 算清楚」**，不要用「验清楚」——「验」字会让观众误以为要进实验室，与实际形式不符。实战中被用户纠正过：「今天老谢用一分钟，一个一个给你验清楚」→ 改为「把这三个说法，一个一个说清楚」。

14. **字数硬指标 1200 字（Word 口径），压缩优先砍修辞不砍信息**。信息点（数据、文献、严谨性三句、吐槽点、承接语）一个都不能少，要压就压虚词、赘语、重复的修饰。压缩手法：删纯提示句（如"这俩名字先记住"）、把"这件事本身"缩成"本身"、"来源排下来是这样"缩成"来源是这样"、去掉不影响语义的"那/就/的"。**不要为了凑字数删掉活人感吐槽或生活化例子**——那是完播率资产。

15. **数字不能连着砸，要拆开、加缓冲**。连续出现三个以上数字（尤其专业量纲）是掉线重灾区。处理手法：
    - **先给大白话解释，再给数字**：×「暴露边界值 MOE 低于 10000 需关注，我国 1142，幼儿高暴露 104」→ √「他们看的是暴露边界值 MOE——摄入量和致病量差多少倍，低于 10000 就得盯紧。……咱们国人是 1142；**可孩子没这么幸运**，……只剩 104」
    - **两两之间插一句转折/情绪缓冲**（"那是不是就没事了？""可孩子没这么幸运"），把数字变成叙事。
    - **同一个量纲尽量合并**：如果两个剂量指标（如"五六十倍"和"MOE"）口径不同，容易让观众混乱，考虑只留一个，或明确用"单看剂量……可国际上不这么算"过渡。
    - 实战中被用户点名：「MOE、1142、104 连续出现，容易让观众掉线」。

16. **食品安全类内容要主动规避平台风控词**。带"下毒""投毒""毒害""致命""毒食品"以及**单字「害」（害你、害人）**这类词的标题和口播，容易被平台判定为夸大/制造恐慌而限流。冲突感要**换一种方式表达**：
    - ×「那到底是谁，在给你'下毒'」→ √「那到底是谁，在天天制造它」
    - ×「空气炸锅到底是不是在'害你'」→ √「空气炸锅到底是不是在'伤你'」
    - 冲突感可以靠"最荒诞的是……""这六年它才是最冤的那个""排第一的，根本不是它"来承载，不必用重口动词。
    - 另外，任何指控句都要**明确归因**（"网上说""有人说"），不能写成稿子自己在断言，否则同样触发夸大判定。
    - 判断标准：**用户自己写的稿子也照改**。用户曾亲手写"是不是在害你"，按同一风控标准仍需替换为"伤你"——风控审核的是词，不看作者是谁。

**正文规则**：
- 每层开篇留悬念，答案压到该层末尾
- 每层至少嵌 1 处文献，写法：《期刊名》+ 年份 + 核心结论
- 口语化短句，一句只讲一个信息
- 禁用「综上所述」「由此可见」「值得注意的是」等书面语

**画中画规则**：只允许期刊截图、新闻/官方通报截图、现成产品图、分子结构或流程示意图、字幕/公式动画这五类；其余一律写成"不需要拍的画面"。

结构范式与完整样例见 `references/template-framework.md`。

### 阶段 5 · 文档成型
1. 先输出 **Markdown 全文**给用户审阅（方便直接改字），停下等确认。用户若直接说「输出最终文档」，视为已通过，直接出 docx。
2. 确认后转 **docx**：按 `tencent-local-office-edit` skill 走下面这套已验证的路径，**结构与模版一致、不加封面页**，然后 present 给用户。


### 阶段 6 · 交付自检
- [ ] 每条文献真实存在、题录完整、可在知网复核
- [ ] 无编造数据、无"专家称"式模糊引用
- [ ] 钩子 ≤2 句、≤40 字，且是直击痛点的反问；没有任何铺垫
- [ ] 钩子第一句打「健康焦虑」，具体对象（产品/物件名）放在第二句
- [ ] 钩子用了「预期违背」结构（先立预期再砸掉），且钩子列的指控数与正文判决数、标题口径一致
- [ ] 钩子里没有点名任何具体物质名/术语（丙烯酰胺、AGEs 等），改用"看不见的变化"这类悬念表述
- [ ] 相邻两层话题不同时，新层开头有一句"桥"把两个话题缝起来
- [ ] 没有三个以上数字连着出现，数字之间有解释或情绪缓冲
- [ ] 标题与口播无「下毒／投毒／毒害／致命」等易触发平台风控的夸大词，指控句均有归因
- [ ] 钩子和结尾的承诺语是「说清楚/讲清楚/算清楚」，没有出现「验」「做实验」「实测」
- [ ] 第一层首句直接下定义（「XX 是……」），没有「要聊这事，得先请出……」这类硬过渡
- [ ] 每层开头都有承接语，上一层的疑问和本层的开头咬合
- [ ] 通篇有活人感，至少 2 处吐槽/口语化表达
- [ ] 没有把文献句式直接搬进稿子（机理、标准名、法规号都已口语化，数据未改）
- [ ] 至少有一层「大家都不知道」的深挖（标准逻辑 / 监管空白 / 产业链 / 暴露来源结构）
- [ ] 钩子里列出的每一条指控，正文都逐条给了判决（被夸大 / 没证据 / 确有来头），没有"挖坑不填"
- [ ] 3 秒钩子内没有任何专业术语；术语首次登场在第一层且有白话解释
- [ ] 通篇无「席夫碱」「Amadori 重排」「Strecker 降解」这类课堂词汇，机理已口播化
- [ ] 反转点前面埋了悬念、标题带冲突，但没有提前揭晓
- [ ] 每处"没证据"后面都跟了限定语，不会被听成"绝对安全"
- [ ] 剂量数字已换算成体感表达，没有论文式量纲复述
- [ ] 每一层结尾都没有总结句，只用疑问或悬念接下一层
- [ ] 最后有一处反转＋一句可记住的升华
- [ ] 正文 1200 字左右（±10%；深挖层多的选题放宽到 +15% 并主动说明）
- [ ] 压缩字数时只砍修辞赘语，数据／文献／严谨性限定语／吐槽点／生活化例子一个未少
- [ ] 所有画中画要求都可现成获取
- [ ] 结尾话术与模版风格一致
- [ ] 立场由证据决定，无预设

## 踩坑记录

- 用户要的是「知网真实期刊」，但我没有知网权限。**必须在交付物 B 里显式写明"真伪请你在知网复核"**，否则用户会误以为已核实。已确认用户接受这个分工。
- 交付节奏是两段式，不是一次给全。写完 A+B 就要停，不要顺手把正文也写了。
- 文献数量宁少勿滥。热点偏冷门时，3 篇扎实的比 5 篇凑数的强。
- **辟谣类热点最怕"辟过头"。** 一旦事实核查发现传言站得住脚的部分，结论就必须是双层结构：「该破的（传言站不住的地方）+ 该留的（确实存在的风险）」。用暴露量 MOE / 参考剂量这类硬指标去校准警示强度，不要因为"是谣言"就一路平反到底。实战案例：某传言两处核心归因都是错的，但中国人群 MOE 仍低于参考线，最终立场定为"不必恐慌，但不是毫无问题"。
