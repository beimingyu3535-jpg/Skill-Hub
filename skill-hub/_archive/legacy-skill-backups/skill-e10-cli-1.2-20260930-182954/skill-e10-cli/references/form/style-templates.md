## 用法

```bash
# 用模板名（推荐，好记）
e10-cli form layout init <objId> <appId> --style-template 标准版

# 或用 id
e10-cli form layout init <objId> <appId> --style-template 700000000000000007

# 指定视图 + 只读/必填
e10-cli form layout init <objId> <appId> --view-id <viewId> --style-template 紧凑版 --read-only
```

## 注意

- 模板只影响**布局样式**（间距/边框/配色），不影响字段的 readOnly/required（这俩由 `--read-only`/`--required` 或 fields.json 控制）。
- `表格版`（008）历史问题：生成的 comps 默认 readOnly=true。`form layout init` 会显式按 `--read-only`（默认 false 可编辑）覆盖，所以即使用 008 也能可编辑。
